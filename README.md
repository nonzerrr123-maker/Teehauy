# Teehauy

Next.js implementation of the Dream Lottery Number App UI referenced from Figma Make.

## Stack

- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Recharts

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current UI flow

- ตีเลขฝันจากข้อความหรือหมวดยอดนิยม
- หน้าผลการตีเลข + favorite/share
- คลังฝันพร้อมค้นหาและกรองหมวด
- ประวัติและรายการโปรด
- สถิติหวยย้อนหลังแบบตาราง/กราฟ
- โปรไฟล์และการตั้งค่าการแจ้งเตือน

> Current interpretation data is prototype data derived from the Figma reference. API/database integration should replace the local demo logic in a later backend phase.
